# Repo Flatten Spec

**Date:** 2026-09-07
**Scope:** Remove deprecated `v1/` directory, flatten `v2/` to root

## Goal

Clean up the repository structure by removing the deprecated `v1/` directory and flattening the active `v2/` codebase to the repo root. This eliminates the version-prefixed directory structure that existed during v1→v2 migration.

## Current Structure

```
training-tracker/
├── v1/          ← deprecated (Streamlit app, garminconnect-mcp)
├── v2/          ← active codebase
├── docs/
├── .gitignore
└── AGENTS.md
```

## Target Structure

```
training-tracker/
├── dashboard.py
├── gateway.py
├── garmin_http.py
├── normalize.py
├── pipeline.py
├── profile.py
├── session.py
├── store.py

├── e2e_report.py
├── metrics/
├── tests/
├── data/           ← gitignored (SQLite)
├── cache/          ← gitignored
├── docs/
├── pyproject.toml
├── .gitignore
└── AGENTS.md
```

## Approach

**Two-commit approach (Approach B):**

### Commit 1: Remove v1

- `git rm -r v1/`
- Update `AGENTS.md`: remove v1 layout description (lines 5-6)
- Clean doc reference: `docs/superpowers/plans/2026-08-30-v2-running-metrics-measurement.md` line 225 (`../v1/cache/garmin_raw.json`)

### Commit 2: Flatten v2

- Move to root:
  - `backfill_names.py`, `backfill_sports.py`, `dashboard.py`, `e2e_report.py`
  - `garmin_fields.py`, `garmin_http.py`, `gateway.py`, `metric_series.py`
  - `normalize.py`, `pipeline.py`, `profile.py`, `session.py`, `store.py`
  - `metrics/` directory
  - `tests/` directory
  - `pyproject.toml`
  - `data/` directory (gitignored)
  - `cache/` directory (gitignored)

- Delete (don't move):
  - `.mypy_cache/`
  - `.pytest_cache/`
  - `__pycache__/`

- Update path references:
  - `AGENTS.md`: rewrite layout section, remove "run from v2/" notes
  - `backfill_sports.py` line 2: usage comment (`Usage (from v2/):`)
  - `backfill_names.py` line 2: usage comment
  - `dashboard.py` line 3: usage comment
  - `e2e_report.py` line 3: usage comment

## Notes

- Git history is preserved (`git rm` only removes from working tree, not history)
- `.venv/` stays at repo root (already there)
- `pyproject.toml` paths (`pythonpath = ["."]`, `testpaths = ["tests"]`) remain correct after flattening
- `docs/superpowers/` references to `v1/` are historical context (why v2 exists) — leave intact except the `../v1/cache/` code reference
- Cache directories (`.mypy_cache`, `.pytest_cache`, `__pycache__`) are regenerated by tools, not moved
